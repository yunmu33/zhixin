# 知新 · 情绪小屋

一句话科普：一款**纯本地**的心情打卡与日记 App。记录每天的心情、收获和日常，用连续打卡看到自己的坚持轨迹。

> 所有数据只保存在这台设备上，不上传任何云端。

---

## 功能一览

五个底部页签：

| 页签 | 内容 |
|---|---|
| 🎯 任务 | 自建打卡任务（阅读 / 运动…），每天打一次卡，每个任务有自己的热度日历 |
| 🗓 待办 | 按天记录的待办清单，可以翻到其他日期补看 |
| 🌱 日日新 | 每天记一条新收获，哪怕一句话，随机灵感例子，连续记录火花 |
| 😊 心情日记 | 27 种手绘心情打卡，配月历；写的日记支持心情 / 分类筛选、搜索、编辑、回收站 |
| 👤 我的 | 头像昵称签名、等级明示、数据概览、成就徽章、小屋设置、数据备份 |

### 🌱 日日新

- 每天一句话记录新收获，随机展示灵感例子
- 一天限写一条，提交后按钮变灰显示「回顾昨天，期待每天」
- 双统计卡片：🔥 连续记录 + 📚 累计收获
- 收获时间线，点击任意一条弹出编辑对话框（悬浮窗修改）
- 底部 slogan：「给自己这一天取一个响亮的 title 吧！」

### 😊 心情日记

- 月历视图，每天一个**手绘表情**记录心情（记过的日子直接显示你选的那张图）
- 日期从周一开始，今天未打卡显示 ⭐ 星星提醒
- 点击日期弹出**圆形心情选择器**：27 颗手绘表情分内外两圈排布，点一下直接打卡
- 27 种心情各不相同：开心、笑哭、心动、亲亲、俏皮、调皮、得意、满足、平静、乖巧、坏笑、淡定、惊讶、震惊、慌张、委屈、难受、生气、赌气、暴怒、低落、想哭、难过、大哭、发晕、受伤、生病
- 手绘图同时出现在：月历、打卡/写记录的心情卡片、统计页情绪分布、记录详情
- 全屏选择页面，左上角显示日期，右上角关闭按钮

### 📔 小屋日记

- 与日日新数据完全分离，专注长文日记
- 心情筛选：27 种心情的手绘图标，横向滑动挑选
- 分类筛选：闷闷 / 小美好 / 小日常
- 支持搜索、编辑、回收站

### 👤 我的 / 我的信息

- 点头像、昵称或「改资料」进入**我的信息**页
- 右上角「编辑」进入编辑态，可改昵称与签名，点「完成」保存
- **换头像**：编辑态点头像弹出选择弹窗——内置表情头像，末尾 ➕ 从相册挑一张照片做头像（图片存进 App 私有目录，换掉时旧文件自动清理）
- 档案数据：加入小屋天数、连续打卡、有记录的日子、新收获条数

### 🏠 主页

- 精简设计：热度总览 + 三个打卡入口 + 小屋书桌
- 移除顶部按钮、打卡提醒卡片、最近小故事展区

### ⚙️ 小屋设置

- 分组卡片式设计：外观与皮肤、使用设置（提醒 / 标签 / 密码锁 / AI）、安全与数据、AI 整理、关于知新
- 入口在「我的」页面

#### 每日记录提醒

- 时间用**上下滑动的滚轮**挑，小时 23 之后接着 0、分钟 59 之后接着 0（循环滚动）
- **循环方式**滚轮：🔁 每天 / 💼 工作日 / 🌴 周末 / 📅 每周（选「每周」时多出一个星期滚轮）
- 「下次提醒」按循环规则算：同一天显示「今天 02:00」、明天显示「明天 02:00」、更远显示星期，例如「周五 02:00」
- 到点响完会按规则自动排下一次（比如只工作日提醒，周五响完排到下周一）；手机重启后也会重新排上
- ⚠️ 在系统设置里对 App 点了「**强制停止**」，Android 会把排好的闹钟全部清掉，得重新打开一次 App 才会再排上

## 隐私与数据

- 所有记录写在 App 私有目录的 `files/mood_house.json` 里，**没有任何云端同步**
- 唯一的联网行为是 **AI 整理**：只有在「AI 分析」里填了 API Key 并保存之后，才会把**当前正在写的这一篇**（正文 + 选的心情）发到你填的那个接口；不填 Key 就完全离线，改走本地模板兜底（输出格式和 AI 版一致）
- API Key 明文存在本机的 SharedPreferences 里
- 「导出」会把全部记录写成一个 JSON 备份文件，「导入」可以把它导回来（按 id 去重）

## 覆盖下载更新（不丢数据）

只要满足下面三个条件，新 APK 就能直接覆盖安装升级，**已有记录全部保留**：

1. **包名不变**：`com.example.zhixin`
2. **签名一致**：所有版本都用项目根目录的 `zhixin.jks` 签名（debug 与 release 已配置同一个签名，见 `app/build.gradle.kts` 的 `signingConfigs`）
3. **versionCode 递增**：新版本的 `versionCode` 必须比手机上已安装的大

### 发布新版本的步骤

1. 修改 `app/build.gradle.kts`：

```kotlin
versionCode = 5        // 必须 +1（或更大）
versionName = "1.5.0"  // 同步更新
```

2. 打包：

```
gradlew assembleRelease
# 输出：app/build/outputs/apk/release/app-release.apk
```

3. 安装升级（任选其一）：
   - 手机下载 APK 后点击安装
   - 或连 USB 执行 `adb install -r app-release.apk`

> ⚠️ **Keystore 文件 `zhixin.jks` 必须保存好且不要更换。**一旦丢失或换用别的签名，用户就必须卸载重装（数据会丢）。
> 别名 / 密码：
> - `storeFile = zhixin.jks`，`storePassword = zhixin2026`
> - `keyAlias = zhixin`，`keyPassword = zhixin2026`

### 从旧版（1.0.0 之前的 debug 签名包）升级

旧包用的是 Android Studio 默认的 debug 签名，与 `zhixin.jks` 不一致，**第一次需要卸载重装一次**：

```
adb uninstall com.example.zhixin
adb install app-release.apk
```

之后的版本都能正常覆盖升级。建议卸载前先在「设置 → 导出」备份数据，装好后「导入」即可恢复。

## 项目结构

```
app/src/main/java/com/example/zhixin/
├── data/           数据层：Entry 模型、日期工具 DateKey、热度与等级 Heat、偏好 Prefs、存储 Store、
│   │               账号 Account、图片存储 ImageStore、Mood 枚举（27 种心情）、
│   │               提醒循环规则 RemindRepeat
├── notify/         每日打卡提醒：ReminderReceiver（闹钟 / 通知 / 到点续排）、ReminderHelper
├── ai/             AI 整理小结（可选，填 Key 后用；没填 Key 走本地模板）
├── ui/
│   ├── components/ 通用组件：SoftCard、StatCard、PrimaryButton、Chips、图表、月历、
│   │               等级明示与各等级阶梯 LevelBlocks
│   ├── screens/    各个页面：TasksScreen、TodoScreen、NewScreen、MoodScreen、MineScreen、
│   │               ProfileScreen、SettingsScreen、TaskHeatScreen、AchievementScreen…
│   ├── theme/      主题、皮肤、配色、心情表情素材映射 MoodIcons
│   └── AppRoot.kt  全局路由与五个页签
└── MainActivity.kt
```
